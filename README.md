# Examulator v2

Program (executable) files for Examulator v2

Note: This version of Examulator will only function with the question pools located in the Examulator-Pools-v2 repository.

The {version} indicator reflects a julian date/timestamp for the file. e.g. 26300.120123 indicates the program was built on October 28, 2026 at 12:01:23 pm.

Files include:

| Filename | Description |
| :--- | :--- |
| Examulator-{version}.apk | Android version for individuals who wish to sideload rather than download from the Google Play Store
| Examulator-Program-linux_x64-{version}.zip | Linux version
| Examulator-Program-osx_arm64-{version}.zip | OS/X ARM version
| Examulator-Program-osx_x64-{version}.zip | OS/X X64 version
| Examulator-Program-win_x64-{version}.zip | Windows X64 version

To install, download one of the above zip files, unZip to your installation folder of choice, and the download and install the appropriate question pools. Run "Examulator" to launch the program. The background server will start and a browser window will open with the application GUI.

Optional Diagnostic programs. These are only needed if you wish to help debug the program, send bug reports, etc. Otherwise, ignore them.
